# История изменений Astrum

## Версия 0.2.0 — News Update

### Новые возможности

- Добавлена новостная лента Astrum.
- Теперь новости, важные объявления, анонсы обновлений и предстоящих событий доступны прямо в приложении.
- Добавлена поддержка изображений и интерактивных действий в новостных карточках.
- Реализована возможность ручного обновления новостной ленты.

### Улучшения

- Реализовано локальное кеширование изображений новостей для ускорения повторной загрузки и сокращения сетевого трафика.
- Добавлены информационные сообщения при отсутствии новостей и ошибках их загрузки.

### Исправления

- Исправлена ошибка загрузки стандартного изображения профиля.
- Исправлена логика выбора и загрузки аватарки пользователя из локального кеша.
