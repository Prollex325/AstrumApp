# История изменений Astrum

## Версия 0.1.0 — Первый выпуск

Первый выпуск Astrum. Реализованы основные возможности управления аккаунтом, персонализации профиля, безопасности, навигации и автоматического обновления приложения.

### ✨ Новые возможности

- Добавлены приветственный экран и анимированная загрузка приложения.
- Реализованы регистрация, авторизация и управление пользовательскими аккаунтами.
- Добавлена синхронизация данных профиля с облачной базой данных.
- Реализовано редактирование имени пользователя, биографии и аватара.
- Добавлены загрузка и хранение аватаров в облаке.
- Реализована система безопасности с возможностью установки и изменения PIN-кода.
- Добавлена возможность изменения пароля аккаунта.
- Реализовано отображение информации о системе и устройстве.
- Добавлена система автоматического обновления Astrum через GitHub Releases.
- Создан раздел управления обновлениями с отображением текущей версии, состояния обновления и прогресса скачивания.
- Добавлен журнал изменений приложения.

### 🎨 Интерфейс и навигация

- Создан единый интерфейс настроек Astrum.
- Реализована навигация между страницами и разделами настроек.
- Добавлены переходы назад и вперёд с помощью боковых кнопок мыши.
- Добавлено меню действий с профилем: редактирование, смена и удаление.
- Добавлены плавные переходы, анимации элементов и индикаторы загрузки.
- Улучшено оформление экранов регистрации, авторизации и управления профилем.
- Обновлён внешний вид раздела обновлений.
- Добавлена фирменная иконка Astrum.

### ⚙️ Улучшения

- Переработаны отдельные механизмы навигации между страницами.
- Улучшена обработка ошибок подключения к облачным сервисам.
- Доработаны сохранение и загрузка пользовательских данных.
- Организовано отдельное локальное хранилище настроек, данных авторизации и кэша.
- Улучшено отображение состояния загрузки и скачивания обновлений.

### 🐛 Исправления

- Исправлены ошибки переключения страниц в настройках.
- Устранён сбой при переходе на несуществующую страницу в разделе безопасности.
- Исправлены отдельные ошибки навигации.
- Исправлены незначительные проблемы интерфейса и отображения элементов.
